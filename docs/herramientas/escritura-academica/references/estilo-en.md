# Academic style in English

Use when the document (or a section, like the CIFIN abstract) goes in English. **Rewrite, never translate literally**: Spanish academic prose runs long and nominal; English prefers short, active, verb-driven sentences.

## Register

- **Active voice by default**, first person plural ("we") accepted in most engineering venues; "this study" / "this paper" for single-author when "I" feels off. Passive only when the agent is irrelevant ("Data were collected…").
- **Sentences 15–25 words.** If a Spanish sentence has three clauses, it becomes two English sentences.
- **Hedging to evidence strength:** suggests / indicates / shows / demonstrates (strongest, needs experimental design).
- **Tense:** past for what you did and found; present for established facts and what the paper argues.
- **Numbers:** words for zero–nine in prose, numerals for 10+ and anything with units. Decimal point. Thousands with comma (10,000).

## Words that flag AI or filler (avoid)

delve, tapestry, landscape ("in today's landscape"), realm, pivotal, crucial (overused), leverage (as verb, overused), robust, seamless, holistic, cutting-edge, game-changer, "it is worth noting that", "plays a vital role", "in conclusion, it can be said", "not only… but also" (max once), triads of adjectives, em dash in every sentence.

## Spanish-speaker traps

| Spanglish / calque | English |
|---|---|
| "actually" (= actualmente) | currently |
| "eventually" (= eventualmente) | occasionally / possibly |
| "assist to the congress" | attend the conference |
| "realize an analysis" | perform / conduct an analysis, or just "analyze" |
| "the 80% of users" | 80% of users (no article) |
| "the technology is important" (generic) | technology is important |
| "informations", "researches", "softwares", "feedbacks" | uncountable: information, research, software, feedback |
| "make a question" | ask a question |
| "depend of" | depend on |
| "consist in" | consist of |
| "in base of" | based on |
| "propose to do" | propose doing / propose that… |
| "explain me" | explain to me |
| "since 2020 the system works" | the system has worked since 2020 (present perfect) |
| "discuss about" | discuss (transitive) |
| "the people" (generic) | people |
| comma splice: "The model failed, it lacked data." | semicolon, period, or conjunction |

## Titles

- **APA 7 title case** for paper titles and headings: capitalize major words and any word of 4+ letters ("Versioned Operational Memory for AI Assistants: A Longitudinal Case Study").
- Reference-list article titles: **sentence case** (only first word, first word after colon, proper nouns).

## Abstract conventions

- No citations, no undefined acronyms, no "In this paper we will…". Start with the problem or the objective.
- Keywords: lowercase unless proper noun, separated as the venue asks (CIFIN: semicolons, max 5).
- The English abstract must say the same as the Spanish one: same numbers, same claims, same order.
