## Definiciones (verbatim)

**Inteligencia en negocios** (slide 3) — misma definición que en la sesión de saberes previos:
> Se refiere al uso de datos en una empresa para facilitar la toma de decisiones. Abarca la comprensión del funcionamiento actual de la empresa, bien como la anticipación de acontecimientos futuros, con el objetivo de ofrecer conocimientos para respaldar las decisiones empresariales.

**Análisis de negocios (BA) vs. análisis de datos** (slide 4):
> El análisis de negocios (BA) se refiere a la práctica de usar los datos de tu empresa para anticipar tendencias y resultados. El análisis de datos es el proceso técnico de la extracción de datos, limpieza de datos, transformación de datos y construcción de sistemas para gestionar datos. El análisis de datos toma grandes cantidades de datos externos para encontrar tendencias y resolver problemas.

**Qué incluye BI** (slide 5): minería de datos · estadística · modelado predictivo.

**Ciencia de datos** (slide 7):
> Combina múltiples campos, como las estadísticas, los métodos científicos, la inteligencia artificial (IA) y el análisis de datos para extraer el valor de los datos. Los practicantes de la ciencia de datos se llaman científicos de datos y combinan una variedad de conocimientos para analizar los datos recopilados de la web, teléfonos inteligentes, clientes, sensores y otras fuentes para obtener información útil.

**Minería de datos** (slide 8):
> Es un campo de la estadística y las ciencias de la computación que intenta descubrir patrones en grandes volúmenes de conjuntos de datos. Utiliza los métodos de la inteligencia artificial, aprendizaje automático, estadística y sistemas de bases de datos. El objetivo general del proceso de minería de datos consiste en extraer información de un conjunto de datos y transformarla en una estructura comprensible para su uso posterior.

**Minería de datos vs. ciencia de datos** (slide 9) — la distinción que la profe subraya:
> La ciencia de datos **en un área** y la minería de datos **es una técnica**. La ciencia de datos es un conjunto de operaciones de datos que también incluye la minería de datos.

## Cómo se ordenan los conceptos

Jerarquía implícita en la presentación (útil para un examen de opción múltiple):

```
Ciencia de datos          ← ÁREA (estadística + método científico + IA + análisis de datos)
  └── Minería de datos    ← TÉCNICA dentro del área
Inteligencia de negocios  ← incluye minería de datos + estadística + modelado predictivo
Análisis de negocios (BA) ← práctica: anticipar tendencias y resultados con datos propios
Análisis de datos         ← proceso TÉCNICO: extraer, limpiar, transformar, construir sistemas
```

El eje que separa BA de análisis de datos es **negocio vs. técnica**, no herramienta. Es la trampa más probable de un examen.
