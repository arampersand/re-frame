## For future Claude

Entregable escolar de [[Fora]] para **Negociación empresarial** (UTCH, cuatri iniciado 2026-08-26, asesora Karina Edith Jiménez Lozano). Tarea "1.2 Estilos de negociación": analizar 3 casos de conflicto e identificar el estilo de negociación de cada actor. Generado y **entregado en Moodle el 2026-09-18** (status submitted, assignid 1018), aunque vencía el 2026-09-20.

## Consigna

Analizar 3 casos (Caso 1 proveedor exclusivo/conflicto de costos; Caso 2 fusión de departamentos/conflicto de procesos; Caso 3 contrato de prácticas/conflicto de intereses), identificar el estilo de negociación y si se prioriza relación vs. resultado, usando una tabla (Caso / Estilo / Enfoque / Diagnóstico). Portada con datos institucionales, materia, título, asesor, alumno, carrera, fecha. Arial 12, interlineado 1.5, justificado. Pedía además una coevaluación de un compañero, que **Fora pidió quitar** (se llena en clase con instrumento de la profa) — el documento entregado NO la incluye.

## Contenido entregado

4 páginas: Portada UTCH · 1. Objetivo · 2. Marco de referencia (5 estilos: competitivo/distributivo, acomodativo, evitativo, colaborativo/integrativo, comprometido) · 3. Análisis de casos (tabla + párrafo por caso) · 4. Conclusión.

Diagnósticos: Caso 1 = competitivo (proveedor) vs. evitativo/ruptura (startup), perder-perder. Caso 2 = colaborativo/integrativo, ganar-ganar. Caso 3 = competitivo (firma) vs. acomodativo (estudiante), acuerdo insostenible.
